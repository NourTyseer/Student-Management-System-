# Student Management System (CLI) 🎓

A simple command-line application built with **Python** to manage student records. 

> 💡 *Note: This is my very first programming project, developed during my first semester at university as part of my journey into software development.*

## ✨ Features
- **Add Student:** Register new students with unique numeric IDs and names.
- **View All Students:** Display a formatted list of all registered students and the total count.
- **Search Functionality:** Find students easily by their **ID** or **Name** (case-insensitive).
- **Delete Student:** Remove a student record with a confirmation prompt.
- **Data Persistence:** Save records to a local text file (`students.txt`) and load them anytime.
- **Input Validation:** Handles invalid inputs and prevents duplicate student IDs or program crashes.

## 🛠️ Technologies Used
- **Python 3** (Core concepts: Functions, Lists, Loops, Exception Handling, and File I/O).

## 🚀 How to Run
1. Make sure you have **Python 3** installed on your computer.
2. Clone this repository or download `student_management.py`.
3. Open your terminal/command prompt in the project folder and run:
   ```bash
   python student_management.py
   ```
